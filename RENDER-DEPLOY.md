# Easy Price — деплой на Render (без локальной сети)

Этот проект запускается на Render как **один Web Service**: сервер Express отдаёт API **и** собранный веб-интерфейс с одного домена. После деплоя любой компьютер/телефон просто открывает ссылку — локальная сеть не нужна.

## Что изменено для деплоя

- `backend/src/server.ts` — если существует `frontend/dist`, сервер раздаёт SPA-фронтенд и все неизвестные маршруты отдаёт через `index.html` (чтобы работал react-router).
- `frontend/src/api.tsx` — по умолчанию API берётся по **относительному пути `/api`** (тот же хост, что и сайт). Ручная настройка «Подключение к ноутбуку» в профиле больше не показывается, если пользователь не задавал свой адрес.
- `frontend/package.json` — добавлен скрипт `start` (`vite preview`), пригодится, если захотите отдавать фронт отдельным сервисом.
- `render.yaml` — конфигурация BluePrint: free-план, автоматическая сборка backend + frontend, health-check `/api/health`, переменные окружения (`MONGODB_MEMORY=1` — встроенная Mongo без внешней БД; `JWT_SECRET` генерируется автоматически).
- `.gitignore` — чтобы в репозиторий не попали `node_modules`, `dist`, `android`, `.env`, APK и локальные данные.

## Как задеплоить

1. Залейте папку проекта (корень — папка с `backend/`, `frontend/` и `render.yaml`) на GitHub (например, через GitHub Desktop или `git init && git add . && git commit -m "render deploy" && git push`).
2. Зайдите на [render.com](https://render.com) → **New → Blueprint** → подключите репозиторий. Render сам подхватит `render.yaml`, соберёт проект и выдаст публичный адрес вида `https://easyprice-xxxx.onrender.com`.
3. Дождитесь статуса **Live**. Откройте ссылку с любого устройства — она работает и без локальной сети, и без ручного ввода адреса сервера в приложении.

## Важные ограничения free-плана

- **Данные временные.** Встроенная Mongo хранится в памяти процесса: при каждом деплое/перезапуске/сне база очищается. Для постоянных данных подключите бесплатный [MongoDB Atlas](https://www.mongodb.com/atlas): создайте кластер, возьмите строку подключения и укажите её в переменной `MONGODB_URI` в настройках сервиса Render (тогда `MONGODB_MEMORY` уберите или поставьте `0`).
- **Сон после простоя.** Бесплатный сервис засыпает после ~15 минут без трафика; первый запрос после простоя откроет сайт через 30–60 секунд.
- Загруженные изображения (`/uploads`) тоже не переживают перезапуск на free-плане — при необходимости подключите Render Disk или облачное хранилище.

## Локальный запуск (как раньше)

```bash
cd backend && npm run dev      # http://localhost:3000
cd frontend && npm run dev     # http://localhost:5173
```

В профиле по-прежнему можно указать адрес «ноутбука», чтобы телефон в одной Wi-Fi сети ходил на локальный сервер.
